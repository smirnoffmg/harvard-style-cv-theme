# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed
- No broken GitHub link and no GitHub API calls when `github:` is unset: `jekyll-github-metadata` filled `site.github` with its metadata object, which the template rendered into the link and which failed builds with HTTP 429
- Long lines on wide screens: the CV column is capped at `40rem` (~86 characters per bullet line)
- LeetCode URL in the print version now includes `/u/`, matching the link target

### Security
- Social links opening in a new tab now carry `rel="noopener"`

### Changed
- Releases follow Conventional Commits: `feat` bumps minor, `!` or a `BREAKING CHANGE:` footer bumps major, and docs/ci/chore-only pushes no longer release
- Release notes are generated by GitHub instead of a fixed template; the archived `actions/create-release` is replaced with `gh release create`
- CI builds a site with only the required fields against the current checkout instead of a remote theme step that could not fail
- README screenshots retaken with the current layout
- `CONSTITUTION.md` brought in line with the code

## [1.1.0] - 2026-05-31

### Added
- Bullets are rendered as Markdown, so links in them are clickable

## [1.0.4] - 2025-12-12

### Changed
- Yandex.Metrika switched to the current counter snippet

## [1.0.3] - 2025-12-12

### Added
- Optional Yandex.Metrika counter (`yandex_metrika`) with goals for contact and social link clicks

## [1.0.2] - 2025-08-02

### Changed
- README updates

## [1.0.1] - 2025-07-24

### Fixed
- Release workflow creates the ZIP archive before uploading it

## [1.0.0] - 2025-07-24

### Added
- Initial release of Harvard-style CV Jekyll template
- Classic Harvard layout with centered header
- Responsive design for desktop, tablet, and mobile
- Print-optimized CSS with separate print stylesheets
- Social media integration (LinkedIn, GitHub, Twitter, Telegram, LeetCode)
- Modular YAML-based content management
- GitHub Pages compatibility with remote theme support
- SEO optimization with jekyll-seo-tag
- Comprehensive documentation and examples

### Features
- Bold centered name and contact information
- All-caps section headings with horizontal rules
- Left-aligned institution/title, right-aligned date/location
- Bullet-point lists for achievements and details
- Times New Roman typography for academic appearance
- 1-inch margins and 1.3 line height for print compatibility
- SVG-based social icons with print fallbacks
- Conditional rendering for optional fields
- HTML support in bullet points for formatting
- GitHub Actions CI, automated semantic-versioned releases and GitHub Pages deployment
